# Health System Analysis

## Overview

Health System Analysis is a Java-based project that evaluates different aspects of a person's daily habits and health indicators.
The system analyzes data such as mood, movement, focus level, and screen time to produce an overall health assessment.

## Features

* Mood evaluation
* Movement analysis
* Screen time tracking
* Focus level measurement
* Overall health analysis

## Project Structure

* **Main.java** – Entry point of the program
* **Person.java** – Represents a person and their data
* **HealthSystem.java** – Core system logic
* **HealthSystemGUI.java** – Graphical User Interface
* **MoodScale.java** – Mood evaluation module
* **MovementScale.java** – Movement analysis module
* **ScreenTimeScale.java** – Screen usage analysis
* **FocusScale.java** – Focus level evaluation
* **OverallAnalysis.java** – Final health analysis and report

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
