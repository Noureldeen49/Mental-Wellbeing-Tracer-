# Health System Analysis

This project is a simple health analysis system developed using Java.

The system analyzes different aspects of a person's health such as:
- Mood
- Movement
- Screen time
- Focus level

It generates an overall analysis based on the collected data.

## Files
- Main.java → program entry point
- Person.java → stores person information
- HealthSystem.java → main system logic
- HealthSystemGUI.java → graphical interface
- MoodScale.java → mood evaluation
- MovementScale.java → movement analysis
- ScreenTimeScale.java → screen usage analysis
- FocusScale.java → focus level evaluation
- OverallAnalysis.java → final health analysis
